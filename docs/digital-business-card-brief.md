# Бриф: цифровая визитка Дмитрия Пыткина

## Цель

Создать компактное публичное веб-приложение, которое показывает профиль
Fullstack TypeScript-разработчика Дмитрия Пыткина и три релевантных проекта.
Это тестовое задание демонстрирует TypeScript, Node.js, NestJS, GraphQL,
Prisma, PostgreSQL, Docker и Git без расширения в CMS или личный кабинет.

## Источники данных

Профиль визитки является статичной локальной frontend-конфигурацией. В ней
содержатся имя, роль, краткое описание B2B SaaS-направления, навыки и
согласованные публичные контакты из резюме: Telegram `@pytkin`, email и
телефон. Город не хранится и не отображается.

Проекты хранятся в PostgreSQL и читаются через NestJS/GraphQL:

- **Seller Platform** — коммерческая B2B SaaS-платформа для работы с
  потенциальными клиентами и данными;
- **Webloftdesign** — SaaS-платформа поиска работы и управления наймом.
- **Air Planner** — Telegram-сервис планирования с интеграцией Google Calendar.

Каждая запись содержит название, описание, вклад, стек и порядок. У трёх
исходных записей есть внутренний уникальный `slug`: seed создаёт или обновляет
их по нему и не удаляет дополнительные проекты. В seed нет вымышленных метрик
и недокументированных достижений.

## Техническое решение

```text
React 19 + Vite + Apollo Client
        │ запрос projects
        ▼
NestJS + GraphQL + Prisma
        ▼
PostgreSQL
```

API только read-only. Он публикует единственный запрос `projects`; типов и
запросов `profile`, `contacts` и `skills` в GraphQL нет. Также нет мутаций,
авторизации, ролей и административного интерфейса.

Frontend использует Tailwind CSS 4 и точечно shadcn/ui-совместимый базовый
компонент. Финальный экран — адаптивная визитка с портретом, профилем,
технологиями, тремя карточками проектов и контактами; Apollo Client показывает
состояния загрузки и ошибки для проектов.

## Запуск

`docker compose up --build` локально запускает PostgreSQL, API и frontend.
README описывает команды, переменные окружения и проверку. Облачный деплой не
требуется: проект передаётся как репозиторий с Docker Compose и документацией.
